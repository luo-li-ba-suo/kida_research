ArCHer：在语言行动与 token 两个尺度学习

以完整语言行动为高层动作学习 Q/V，再用轮次优势指导低层 token 生成。

首次发布 2026-11-15 最近更新 2026-11-15
Agentic RL

阅读理解

高层 off-policy value learning 与低层 on-policy 更新承担不同职责，层级划分本身并不保证信用准确。

ArCHer：把完整语言行动作为高层动作

几十轮对话、上千个 token，终局奖励怎样传回早期行动？

遇到的问题长交互只有末尾成败时，早期一整轮行动的好坏很难估计；只在 token 尺度处理，也没有明确表示跨轮次价值。

怎么改把一整轮语言输出当作高层动作，学习 Q/V；用轮次优势指导低层 token 生成。

Aturn=Q(s,a)−V(s)A^{\mathrm{turn}}=Q(s,a)-V(s)

为何有效高层直接学习跨轮次的长期收益，低层据此优化这一轮如何表达和执行。

把信用传播分到两个尺度；同一轮内部的 token 仍可能共享粗粒度优势。

补充说明与适用边界

ArCHer是2024年的基础工作，用来解释层级信用，不把它伪装成2026新工作。高层off-policy value learning，低层on-policy policy gradient，不能说整套都是off-policy。
