GraphGPO：连接已有轨迹，重新分配局部信用

把重复状态连接成图，利用成功距离重估局部信用，并梳理状态等价、成功覆盖和优势融合的限制。

首次发布 2026-11-15 最近更新 2026-11-15
Agentic RL

阅读理解

图结构的价值在于复用已有成功证据；它不会在全组失败、没有成功连接时凭空创造成功路径。

成功的轨迹有绕路，失败的轨迹有好动作

贯穿例子：确定性转移、只有终局奖励、每条边成本为 1

成功：S → U → X → G。
失败：S → X → F。
整轨迹优势会一起奖励上面的动作，一起惩罚下面的动作。

所有图与手算数值均为教学构造。

S→X是捷径，但这次后面选了X→F而失败。不要说它在所有环境中必然好，这里依赖确定性图构造和相同完整状态。

失败前缀，可以接上另一条轨迹的成功后缀

把上一页两条轨迹中的相同 S、X 合并：失败前缀 S → X，接上成功后缀 X → G。

S → X → G

失败轨迹提供：S → X。
成功轨迹提供：X → G。
S → X 其实能接到成功；这次失败来自后续选了 X → F。

两段均真实执行过；完整捷径未被一次采到。用图重算已有动作的信用，不额外生成 rollout。

补充说明与适用边界

直接承接上一页：在GiGPO中S→X被这次失败拉成负局部优势，GraphGPO通过另一条轨迹的X→G，看见它仍然接近成功。状态合并要求可复用的相同任务状态，图距离不是无条件的因果价值估计。

图上的成功距离，提供另一种信用证据

从成功终点反向求距离，再比较同状态下的出边

Rgraph(s,a)=Rsuccηd(s′)+c(s,a)R^{\mathrm{graph}}(s,a)=R_{\mathrm{succ}}\eta^{d(s^\prime)+c(s,a)}
d(X)=1，d(U)=2。
距离近的后继，得到更高图奖励。

再与 episode 优势融合；本例等权相加后，两条 S 出边的总优势都为 0。

补充说明与适用边界

关键不是一定正向强化失败中的好动作，而是改善其局部信用。成功轨迹Aepisode=+1，失败为−1，图优势相反，等权后都为0。这消除了捷径原本的负更新。完整手算在附录。

重复状态是证据，也是一项假设

两个操作实例说明“相同”需要检查哪些字段

网页：相同 URL 不一定代表相同任务状态。
棋盘：玩家位置相同，箱子不同，也不是同一状态。
GUI：截图相似可能掩盖任务进度差异。
